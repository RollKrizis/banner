# TG-бот: баннер в середине ролика + срез первых кадров

Кидаешь видео в личку - получаешь готовый файл под TikTok.

## Два режима (`/mode`, по умолчанию `auto`)
- **freeze** - ролик короче 10с: видео встаёт на стоп-кадре ровно посередине на длину
  баннера, звук оригинала тоже паузится и склеивается без рассинхрона.
  `FREEZE_BLUR=8` даёт размытый фон под баннером.
- **duck** - ролик длиннее 10с: без остановки, баннер поверх видео, а звук ролика
  плавно уходит до 18% (`DUCK`) на время баннера и возвращается. Голос с баннера
  идёт через `amix` + `alimiter`, без клиппинга.

В обоих режимах: хромакей баннера выбивается (`colorkey` + `despill`), баннер центруется,
первые N кадров срезаются вместе с аудио, метаданные вычищаются.

## Запуск
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # нужен установленный ffmpeg
cp .env.example .env                     # вписать BOT_TOKEN
set -a && . ./.env && set +a && python bot.py
```
Или: `docker build -t banner-bot . && docker run --env-file .env -v $PWD/banners:/app/banners banner-bot`

## Команды
`/mode auto|freeze|duck` · `/size 1080x1920` · `/fit auto|cover|contain|blur` · `/limit 10` · `/duck 0.18` · `/vol 1.4` · `/blur 8` · `/cut 3` ·
`/scale 0.92` · `/pos 0.5` · `/key 0x00FF00 0.30 0.12` · `/jitter on|off` ·
`/banner` (ответом на видео) · `/settings`

## Анти-бан
Срез первых кадров + полный ре-энкод -> новый видеохеш; `-map_metadata -1` чистит
метаданные; `JITTER=1` добавляет случайный кроп 1-2 px, так что каждый прогон уникален.

## Автосжатие видео

Если видео больше 20 МБ, бот **автоматически сжимает** его:
- Сохраняет качество (CRF адаптивный в зависимости от размера)
- Уменьшает аудио до 128 kbps
- Использует самый быстрый preset (ultrafast) для сжатия
- Сообщает тебе о прогрессе

Нет нужды предварительно оптимизировать видео! Загружай как есть, бот разберётся.

## Лимиты Telegram
Bot API: скачивание до 20 МБ, отправка до 50 МБ. Для больших файлов - local Bot API server (до 2 ГБ).
Баннер в комплекте: 2054x1080, 30 fps, 3.48с, фон #00FF00, со звуковой дорожкой.

## Разрешение
Всё, что меньше 1080x1920 (`/size`), апскейлится lanczos-ом до целевого кадра.
`/fit auto` (дефолт): почти-вертикальные ролики идут в `cover` (заполнить и обрезать лишнее),
горизонтальные - в `blur` (кадр целиком по центру, сзади размытая заливка вместо чёрных полей).
Ещё есть `contain` (чёрные поля). Видео больше целевого не трогается, SAR всегда 1:1.
